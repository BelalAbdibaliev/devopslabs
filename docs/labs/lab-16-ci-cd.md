# Lab 16 - CI/CD

## Objective
Understand the GitHub Actions pipeline.

## Initial State
Code pushed to main.

## Steps
1. Review .github/workflows/ci-cd.yml. Trigger a build.
2. Observe the results in the appropriate tool (Grafana/Kubectl).

## What to Observe
- Metric changes.
- Log anomalies.
- Pod state changes.

## Questions
**Q:** Does it push to GHCR?
**Expected Observation:** Yes.

## Troubleshooting Hints
- Check Actions tab.
